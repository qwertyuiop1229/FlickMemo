# カラーピッカー

ヘッダーのスポイトボタン、または設定の「カラーピッカー」から利用する。標準キーはCtrl+Alt+C。設定でキー、ショートカットの有効/無効、HEX/RGB/HSL、HEXの大小文字、最近の色の保存を変更できる。最近の色は端末共通で最大12色、クラウドへ送信しない。

Windows版はRegisterHotKeyによってトレイ常駐中も起動する。採色中だけマウスフック、40msのタイマー、GDIの画面DCを使用する。49ピクセルの拡大プレビューと確定した1ピクセルだけを読み、スクリーンショット全体を保持しない。クリック/Enterで選択とコピー、Esc/右クリック/フォーカス喪失/ロック/60秒経過で中止する。矢印キーで1px移動できる。終了後はタイマーとフック、画面DCを解放し、WebViewを追加生成しない。コピーには既存の非記録マーカーを付け、クリップボード同期に意図せず含めない。更新や通常のメモ機能と設定DBを共用するが、色はアカウント別クラウドには書かない。

設定変更は新しいキーを先に登録、DB保存成功後に古いキーを解除する。キーの競合や保存失敗では以前の設定を保持する。起動時にキーが競合してもメモアプリは起動し、手動の採色は使用できる。設定に競合を表示する。

Web/PWA/Chrome・Edge拡張は対応ブラウザのEyeDropper APIを使う。キーはFlickMemoへフォーカスがある間だけ有効。クリック/キーイベント内でopenを呼び、ユーザー操作の要件を満たす。未対応のSafari/Firefox等は説明を表示する。ブラウザで自動コピーが拒否された場合も値を保持し、明示的なコピーボタンを表示する。OS/ブラウザが予約したキーは優先できない場合がある。

保護された画面、セキュアデスクトップ、HDR/広色域/ICC補正の厳密な測色は対象外。色値は通常画面のsRGB表現で、測色器の代替ではない。

試験は合成色と隔離ブラウザ/使い捨てWindows CIだけを使用する。個人端末の画面採色・クリップボード書換え・入力フックの操作試験は行わない。Windows CIでは旧版からの更新・メモ保持試験に続き、実グローバルキー、合成画面の1ピクセル、正確なコピー、Esc時の保持、RGB、履歴オフ、キー無効化を確認する。
